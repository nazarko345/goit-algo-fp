# Фінальний проєкт GoIT — алгоритми та структури даних

У репозиторії реалізовано всі 7 завдань фінального проєкту.

## Встановлення

Потрібен Python 3.10 або новіший.

```bash
python -m venv .venv
```

Активація середовища:

- Windows: `.venv\\Scripts\\activate`
- macOS/Linux: `source .venv/bin/activate`

Встановлення залежностей:

```bash
pip install -r requirements.txt
```

## Запуск завдань

Кожне завдання знаходиться в окремому файлі та запускається незалежно:

```bash
python task1_linked_list.py
python task2_pythagoras_tree.py
python task3_dijkstra.py
python task4_heap_visualization.py
python task5_tree_traversal.py
python task6_food_selection.py
python task7_monte_carlo.py
```

Завдання 2, 6 та 7 запитують параметри користувача. Завдання 2, 4, 5 та 7 відкривають графічні вікна Matplotlib.

## Короткий опис реалізацій

### Завдання 1 — однозв'язний список
- `reverse_linked_list()` змінює посилання між вузлами і розвертає список за O(n) часу та O(1) додаткової пам'яті.
- `merge_sort()` сортує список методом злиття за O(n log n).
- `merge_sorted_nodes()` об'єднує два відсортовані списки за O(n).

### Завдання 2 — дерево Піфагора
Рекурсивна функція `add_square()` малює квадрат і два дочірні квадрати. Користувач задає глибину рекурсії від 1 до 12. Зі збільшенням глибини фрактал стає деталізованішим.

### Завдання 3 — алгоритм Дейкстри
Функція `dijkstra()` використовує `heapq` як бінарну мінімальну купу для вибору вершини з найменшою поточною відстанню. Повертаються відстані та попередники, а `restore_path()` відновлює маршрут. Алгоритм працює з невід'ємними вагами.

### Завдання 4 — візуалізація купи
Масив мінімальної бінарної купи перетворюється на вузли дерева за індексами `2*i+1` та `2*i+2`, після чого дерево візуалізується через NetworkX і Matplotlib.

### Завдання 5 — обходи дерева
- DFS використовує стек.
- BFS використовує чергу `deque`.
- Після кожного кроку створюється окреме зображення дерева. Відвідані вузли отримують відтінки синього відповідно до порядку обходу, невідвідані залишаються сірими.

### Завдання 6 — вибір їжі
- Жадібний алгоритм сортує страви за співвідношенням калорій до вартості. Він швидкий, але не гарантує глобального оптимуму.
- Динамічне програмування розв'язує задачу 0/1-рюкзака й знаходить оптимальний набір за умови, що кожну страву можна обрати не більше одного разу.

### Завдання 7 — метод Монте-Карло
Симулюється задана кількість кидків двох кубиків. Частота кожної суми ділиться на кількість кидків і дає її експериментальну ймовірність. Результати порівнюються з точними аналітичними ймовірностями та зберігаються у графік `dice_probabilities.png`.

## Висновки до завдання 7

Для двох чесних шестигранних кубиків існує 36 однаково ймовірних елементарних результатів. Кількість комбінацій для сум від 2 до 12 дорівнює відповідно:
`1, 2, 3, 4, 5, 6, 5, 4, 3, 2, 1`.

Тому аналітична ймовірність суми дорівнює кількості відповідних комбінацій, поділеній на 36. Метод Монте-Карло оцінює ці ймовірності за відносними частотами в симуляції. Через випадковість результати можуть трохи відрізнятися від точних значень. Зі збільшенням кількості кидків експериментальні оцінки зазвичай наближаються до аналітичних імовірностей (закон великих чисел).
